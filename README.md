# БилимAI (BilimAI) — Интерактивная образовательная платформа с ИИ-репетитором

Интеллектуальная платформа нового поколения для изучения кыргызского и английского языков на базе **Google Gemini AI**, синтеза речи (TTS) и распознавания голоса (Speech-to-Text).

---

## 🌟 Ключевые возможности платформы

1. **Комплексная программа обучения (Кыргызский и Английский языки):**
   - Уровни подготовки от начального (A1) до продвинутого (B2+).
   - Интерактивные диалоги, практические жизненные сценарии (Рынок, Аэропорт, Деловая переписка, Интервью, Традиции).
   - Тематические грамматические разборы, аудио-озвучка и пошаговые упражнения.

2. **Персональный ИИ-репетитор (Живой диалог в реальном времени):**
   - Интеллектуальный чат с поддержкой естественной разговорной речи.
   - Деликатное исправление речевых и грамматических ошибок с пояснениями.
   - Голосовой ввод через микрофон и озвучивание ответов на чистом литературном языке.

3. **Тренажер произношения (AI Pronunciation Coach):**
   - Запись речи учащегося через браузер и оценка точности произношения в процентах (0–100%).
   - Детальный анализ специфических звуков кыргызского языка (**Ө, Ү, Ң** и долгих гласных).
   - Индивидуальные рекомендации по постановке артикуляции.

4. **Интеллектуальный словарь и флеш-карточки (Интервальное повторение):**
   - Интерактивное заучивание слов, озвучивание, примеры в предложениях.
   - Возможность добавления собственных слов из диалога с репетитором.

5. **Геймификация и личный кабинет:**
   - Система очков опыта (XP), серий ежедневных занятий (Streak) и наград.
   - Входное адаптивное тестирование для автоматического подбора программы.
   - Локальная авторизация и синхронизация профиля.

6. **Адаптивный интерфейс и PWA:**
   - Оптимизировано для смартфонов, планшетов и настольных компьютеров.
   - Поддержка установки как PWA-приложение на экран телефона.

---

## 🛠 Технологический стек

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Canvas Confetti.
- **Backend / Proxy:** Node.js, Express, tsx.
- **AI & Speech Core:** `@google/genai` (Gemini 2.5 Flash), Web Speech API, Express TTS Engine.
- **PWA:** Service Worker, Web App Manifest.

## 🚀 Установка и запуск на Linux (Ubuntu)

### 1. Системные требования
- **Node.js** версии 20 или выше
- **npm** (или yarn / bun)
- **Git**

### 2. Клонирование и установка зависимостей
```bash
# Клонируйте репозиторий
git clone https://github.com/ВАШ_ЛОГИН/bilimai.git
cd bilimai

# Установите зависимости
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваш ключ Gemini API:
```env
GEMINI_API_KEY=ваш_апи_ключ_gemini
PORT=3000
```

### 4. Запуск в режиме разработки (Development)
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:3000`

### 5. Сборка и запуск в продакшене (Production)
```bash
npm run build
npm start
```

## 🌐 Развертывание на сервере (Ubuntu VPS + PM2 + Nginx)

Для постоянной бесперебойной работы приложения:
```bash
# Установка PM2 глобально
sudo npm install -g pm2

# Запуск процесса
pm2 start server.ts --name bilimai --interpreter tsx

# Автозапуск при перезагрузке сервера
pm2 save
pm2 startup
```
